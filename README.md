# Interactpedia · 交互百科

面向产品、后端与协作角色的 **UI 交互形式词典**：标准中英命名、可操作演示，以及状态机 / 接口协作要点。

## 文档（全景清单）

中英条目 `id` 对齐，约 195 条：

- [中文全景](docs/ui-interaction-catalog.zh.md)
- [English catalog](docs/ui-interaction-catalog.en.md)

重新生成：

```bash
npm run catalog
```

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 技术栈

React 19 + TypeScript + Vite 5 + React Router。首版站点含 16 条加深词条与 Live Demo；全景文档为命名与扩写基线。
