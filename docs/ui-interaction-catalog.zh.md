# UI 交互形式全景

> 版本：1.0 · 条目数：195 · 与 [English version](./ui-interaction-catalog.en.md) 条目 `id` 完全对齐

## 0. 怎么读这份清单

- 区分三层：**输入原语**（指点、滑动）≠ **界面控件**（按钮、开关）≠ **交互模式**（无限滚动、乐观更新）。
- 同一概念跨平台命名可能不同（如 Toast vs Snackbar）；条目中保留常用别名。
- 不存在权威「绝对全集」；本清单按当代 Web / 移动 / 桌面 / 无障碍 / 协作 / AI 产品常见形态尽量铺全，可继续增补。
- 每条含稳定 `id`、中文名、英文名、一句话定义、大类；部分含适用端与易混淆对象。

## 1. 输入原语 {#primitives}

### `click` 点击
- **英文名**：Click / Tap
- **定义**：用指针或手指按下并松开以激活目标。
- **大类**：1. 输入原语
  - 适用端：通用

### `double-click` 双击
- **英文名**：Double-click / Double-tap
- **定义**：短时间内连续两次点击，常用于打开或进入编辑。
- **大类**：1. 输入原语
  - 适用端：通用
  - 易混淆：`long-press`

### `long-press` 长按
- **英文名**：Long Press / Press and Hold
- **定义**：按住超过阈值阈值以呼出菜单或进入选择模式。
- **大类**：1. 输入原语
  - 适用端：移动/触控
  - 易混淆：`double-click`

### `right-click` 右键 / 呼出菜单
- **英文名**：Right-click / Context Menu Gesture
- **定义**：次要指针键或等效手势打开上下文菜单。
- **大类**：1. 输入原语
  - 适用端：桌面/Web

### `hover` 悬停
- **英文名**：Hover / Mouseover
- **定义**：指针停留在目标上触发预览、高亮或工具提示（触控端通常无此态）。
- **大类**：1. 输入原语
  - 适用端：桌面/Web

### `focus` 聚焦
- **英文名**：Focus
- **定义**：键盘或辅助技术将输入焦点移到可交互元素上。
- **大类**：1. 输入原语
  - 适用端：通用

### `drag` 拖拽
- **英文名**：Drag
- **定义**：按下后移动指针/手指以移动对象或划定区域。
- **大类**：1. 输入原语
  - 适用端：通用

### `drop` 投放
- **英文名**：Drop
- **定义**：在拖拽结束时将对象释放到目标区域。
- **大类**：1. 输入原语
  - 适用端：通用
  - 易混淆：`drag`

### `scroll-pan` 滚动 / 平移
- **英文名**：Scroll / Pan
- **定义**：移动视口以查看超出可见区域的内容。
- **大类**：1. 输入原语
  - 适用端：通用

### `swipe` 轻扫
- **英文名**：Swipe
- **定义**：快速单向滑动，常用于切换、删除或返回。
- **大类**：1. 输入原语
  - 适用端：移动
  - 易混淆：`fling`

### `fling` 抛甩
- **英文名**：Fling
- **定义**：带惯性的快速滑动，内容在松手后继续滑动。
- **大类**：1. 输入原语
  - 适用端：移动
  - 易混淆：`swipe`

### `pinch-zoom` 捏合缩放
- **英文名**：Pinch to Zoom
- **定义**：双指开合改变内容缩放级别。
- **大类**：1. 输入原语
  - 适用端：触控

### `rotate-gesture` 双指旋转
- **英文名**：Two-finger Rotate
- **定义**：双指相对旋转以旋转对象或视图。
- **大类**：1. 输入原语
  - 适用端：触控

### `multi-touch` 多指手势
- **英文名**：Multi-touch Gesture
- **定义**：同时使用两根以上手指完成特定系统或应用手势。
- **大类**：1. 输入原语
  - 适用端：触控

### `force-touch` 力触控
- **英文名**：Force Touch / 3D Touch
- **定义**：按压力度分级触发 Peek/Pop 等快捷预览（平台依赖）。
- **大类**：1. 输入原语
  - 适用端：部分设备

### `stylus` 触控笔交互
- **英文名**：Stylus / Pen Input
- **定义**：用数位笔书写、点选、压感与侧键操作。
- **大类**：1. 输入原语
  - 适用端：平板/桌面

### `keyboard-typing` 键盘键入
- **英文名**：Keyboard Typing
- **定义**：通过物理或屏幕键盘输入文本。
- **大类**：1. 输入原语
  - 适用端：通用

### `keyboard-shortcut` 键盘快捷键
- **英文名**：Keyboard Shortcut
- **定义**：组合键直接触发命令，提升效率用户操作速度。
- **大类**：1. 输入原语
  - 适用端：桌面/Web

### `arrow-key-nav` 方向键浏览
- **英文名**：Arrow-key Navigation
- **定义**：用方向键在列表、网格、菜单或画布中移动焦点。
- **大类**：1. 输入原语
  - 适用端：桌面/Web

### `space-activate` 空格激活
- **英文名**：Space to Activate
- **定义**：焦点在控件上时用空格（或 Enter）激活，符合键盘操作惯例。
- **大类**：1. 输入原语
  - 适用端：桌面/Web

### `ime-composition` IME 组合输入
- **英文名**：IME Composition
- **定义**：中日韩等输入法在确认前处于组合态，需特殊处理校验与搜索。
- **大类**：1. 输入原语
  - 适用端：通用

### `voice-input` 语音输入
- **英文名**：Voice Input
- **定义**：通过语音转写填充字段或触发命令。
- **大类**：1. 输入原语
  - 适用端：通用

### `gamepad` 手柄 / 遥控
- **英文名**：Gamepad / Remote Control
- **定义**：用游戏手柄或电视遥控进行焦点移动与确认。
- **大类**：1. 输入原语
  - 适用端：TV/游戏

### `eye-tracking` 眼球追踪
- **英文名**：Eye Tracking
- **定义**：用视线移动指针或选择目标（辅助或专用设备）。
- **大类**：1. 输入原语
  - 适用端：专用

### `camera-gesture` 相机手势
- **英文名**：Camera / Mid-air Gesture
- **定义**：摄像头识别挥手等空中手势以控制系统（部分设备）。
- **大类**：1. 输入原语
  - 适用端：专用


## 2. 基础控件与其标准交互 {#controls}

### `button` 按钮
- **英文名**：Button
- **定义**：单击触发一个动作的基础控件。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `split-button` 分裂按钮
- **英文名**：Split Button
- **定义**：主操作与下拉次要选项组合在同一控件。
- **大类**：2. 基础控件与其标准交互
  - 适用端：桌面/Web
  - 易混淆：`button`

### `fab` 浮动操作按钮
- **英文名**：Floating Action Button (FAB)；别名：FAB
- **定义**：悬浮在内容之上的主操作入口，常见于移动端。
- **大类**：2. 基础控件与其标准交互
  - 适用端：移动

### `icon-button` 图标按钮
- **英文名**：Icon Button
- **定义**：仅用图标表达动作，需有无障碍名称。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `link` 链接
- **英文名**：Link / Hyperlink
- **定义**：导航到另一资源或页面位置，语义上不同于按钮。
- **大类**：2. 基础控件与其标准交互
  - 适用端：Web
  - 易混淆：`button`

### `text-field` 文本框
- **英文名**：Text Field / Textbox
- **定义**：单行文本输入控件。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `password-field` 密码框
- **英文名**：Password Field
- **定义**：掩码显示的敏感文本输入，常带显示/隐藏切换。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `otp-input` 验证码分位输入
- **英文名**：OTP / PIN Input
- **定义**：多格一位一格的验证码输入，支持自动填充与焦点跳转。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `search-field` 搜索框
- **英文名**：Search Field
- **定义**：专用于查询的输入框，常带清除与提交图标。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `textarea` 多行输入
- **英文名**：Textarea / Multiline Input
- **定义**：可换行的较长文本输入区域。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `checkbox` 复选框
- **英文名**：Checkbox
- **定义**：独立开关某选项，可多选；可有不确定态。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`toggle`

### `radio` 单选按钮
- **英文名**：Radio Button
- **定义**：互斥选项组中只能选一项。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`segmented-control`

### `toggle` 开关
- **英文名**：Toggle / Switch；别名：Switch
- **定义**：立即生效的开/关状态控件，适合设置项。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`checkbox`

### `slider` 滑块
- **英文名**：Slider / Range
- **定义**：在连续或离散范围内拖动选择数值。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `stepper` 步进器
- **英文名**：Input Stepper
- **定义**：用增减按钮以固定步长调整数值。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`slider`

### `select` 下拉选择
- **英文名**：Select / Dropdown List
- **定义**：从预置列表中选择一项（或多项）。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`combobox`

### `listbox` 列表框
- **英文名**：Listbox
- **定义**：常显列表中选择一项或多项，可不折叠。
- **大类**：2. 基础控件与其标准交互
  - 适用端：桌面/Web

### `combobox` 组合框
- **英文名**：Combobox
- **定义**：可输入又可从列表选择的混合控件。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`select`

### `segmented-control` 分段控件
- **英文名**：Segmented Control / Segmented Button
- **定义**：一组互斥分段，用于视图或模式切换。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用
  - 易混淆：`tabs`

### `date-picker` 日期选择器
- **英文名**：Date Picker
- **定义**：通过日历或滚轮选择日期。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `time-picker` 时间选择器
- **英文名**：Time Picker
- **定义**：选择时分秒或时段。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `color-picker` 颜色选择器
- **英文名**：Color Picker
- **定义**：通过色板、光谱或输入值选择颜色。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `file-picker` 文件选择
- **英文名**：File Picker
- **定义**：通过系统对话框选择本地文件。
- **大类**：2. 基础控件与其标准交互

- **英文名**：Drag-and-drop Upload

- **定义**：将多项以芯片形式加入可编辑字段（如收件人）。

  - 适用端：通用

### `rating` 评分
- **英文名**：Rating Control
- **定义**：用星级等离散等级评价。
- **大类**：2. 基础控件与其标准交互
  - 适用端：通用

### `knob` 旋钮
- **英文名**：Knob / Virtual Knob
- **定义**：旋转式连续控制，常见于音频等专业界面。

  - 适用端：专用
  - 易混淆：`slider`

### `wheel-picker` 滚轮选择器
- **英文名**：Wheel Picker

- **大类**：2. 基础控件与其标准交互
  - 适用端：移动


## 3. 导航与寻路 {#navigation}

### `top-nav` 顶部导航栏
- **英文名**：Top Navigation Bar
- **定义**：页面顶部的主导航或工具栏区域。
- **大类**：3. 导航与寻路
  - 适用端：通用

### `bottom-nav` 底部导航栏
- **英文名**：Bottom Navigation / Tab Bar
- **定义**：移动端底部固定的主要目的地切换。
- **大类**：3. 导航与寻路
  - 适用端：移动
  - 易混淆：`tabs`

### `sidebar` 侧边栏
- **英文名**：Sidebar
- **定义**：侧向常驻或可折叠的导航与工具区。
- **大类**：3. 导航与寻路
  - 适用端：桌面/Web

### `nav-rail` 导航轨
- **英文名**：Navigation Rail
- **定义**：窄竖条图标导航，介于底栏与侧栏之间。
- **大类**：3. 导航与寻路
  - 适用端：平板/桌面

### `hamburger-menu` 汉堡菜单
- **英文名**：Hamburger Menu
- **定义**：折叠导航入口，点击展开抽屉或菜单。
- **大类**：3. 导航与寻路
  - 适用端：移动/Web

### `mega-menu` 巨型菜单
- **英文名**：Mega Menu
- **定义**：大面积多列展示的站点级导航面板。
- **大类**：3. 导航与寻路
  - 适用端：Web

### `tabs` 标签页
- **英文名**：Tabs
- **定义**：同一视图内切换相关面板，通常保留上下文。
- **大类**：3. 导航与寻路
  - 适用端：通用
  - 易混淆：`segmented-control`

### `breadcrumb` 面包屑
- **英文名**：Breadcrumb
- **定义**：显示当前位置的层级路径并支持回退。
- **大类**：3. 导航与寻路
  - 适用端：Web/桌面

### `anchor-link` 锚点 / 页内跳转
- **英文名**：Anchor Link / Jump Link
- **定义**：跳转到同一页面内的目标区块。
- **大类**：3. 导航与寻路
  - 适用端：Web

### `back-to-top` 返回顶部
- **英文名**：Back to Top
- **定义**：长页快速滚回页首的快捷控件。
- **大类**：3. 导航与寻路
  - 适用端：Web/移动

### `wizard` 步进向导
- **英文名**：Wizard / Stepper Flow
- **定义**：将复杂任务拆成有序步骤引导完成。
- **大类**：3. 导航与寻路
  - 适用端：通用
  - 易混淆：`tabs`

### `tree-nav` 树形导航
- **英文名**：Tree Navigation
- **定义**：可展开的层级节点导航，常见于文件与设置。
- **大类**：3. 导航与寻路
  - 适用端：桌面/Web

### `pagination-nav` 分页导航
- **英文名**：Pagination Navigation
- **定义**：通过页码或上一页/下一页在结果集间移动。
- **大类**：3. 导航与寻路
  - 适用端：Web
  - 易混淆：`infinite-scroll`

### `history-back-forward` 历史前进 / 后退
- **英文名**：History Back / Forward
- **定义**：沿浏览器或应用导航历史移动。
- **大类**：3. 导航与寻路
  - 适用端：通用

### `deep-link` 深链与 URL 状态
- **英文名**：Deep Link / URL State
- **定义**：用 URL 表达可分享的应用状态与入口。
- **大类**：3. 导航与寻路
  - 适用端：Web/移动

### `app-switcher` 应用切换器
- **英文名**：App Switcher
- **定义**：系统级在近期应用或窗口间切换。
- **大类**：3. 导航与寻路
  - 适用端：系统


## 4. 揭示、叠加与注意力 {#overlays}

### `modal` 模态对话框
- **英文名**：Modal Dialog
- **定义**：阻断背景交互、要求用户先处理的对话框。
- **大类**：4. 揭示、叠加与注意力
  - 适用端：通用
  - 易混淆：`non-modal`

### `non-modal` 非模态面板
- **英文名**：Non-modal Overlay / Panel
- **定义**：浮层出现时仍可与背景交互。
- **大类**：4. 揭示、叠加与注意力
  - 适用端：通用
  - 易混淆：`modal`

### `confirm-dialog` 确认对话框
- **英文名**：Confirm Dialog
- **定义**：在破坏性或重要操作前要求明确确认。
